# Hypotenuse of a Right Triangle Calculator

## Description
This calculator is **designed to compute the hypotenuse of the right triangle.**

## How to Run
Download the file, after downloading it drag the file to PyCharm and run it by clicking 
the run button.

## Input Needed
Enter the following value:

- length of side a
- length of side b

## Sample Output
Enter the length of the shorter side: 6
Enter the length of the second shorter side: 8
The hypotenuse id 10.00
